# Proof of Concept

We believe player collision will work; if it doesn’t, the project should pivot to 2D instead of 3D. This is our riskiest assumption because the game depends on collision. 

If Carnival, the main character, cannot collide with the walls, he’ll phase through the walls of the maze and beat the game all too easily. 


### The result?
It went amazing! The movement and collision works perfectly like we imagined and this will let us focus on the real content of the game

We also worked out a good system for easily building the maze in tiles, so we can efficiently design a good map
