# Carnival In Wonderland
A short maze escape game! Play as Carnival, the titular main fisher cat of the Festivalia franchise! Avoid enemies disguised as his friends! Explore a maze inspired by the classic fairytale, Alice in Wonderland! The gameplay centers exploration and action, but watch out, you’re on a timer so don’t stall around! This game serves to be the introduction to the world and characters of Festivalia, especially if more is to be made in the future.
